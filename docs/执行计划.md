## 下一步执行队列

1. 管理员验收：桌面和手机浏览器完成建批、分货、解锁、关闭/重开、汇总、打印及 `.xlsx` 下载。
2. 员工验收：微信开发者工具或真机完成报 0、解锁后重报、关闭只读、历史触底加载与失败重试。
3. 外部联调：配置微信 AppSecret、HTTPS 合法域名、备份、日志、健康检查与部署说明。
4. 业务追踪增强：为解锁、关闭、重开补充操作审计记录；不改变现有业务流程。

## 发布前最低验证

- 后端：状态闭环、解锁重报、删除限制、历史分页、有效汇总的定向测试。
- 管理员 Web：`npm.cmd run build`。
- 员工小程序：`npm.cmd run build:mp-weixin`。
- 静态检查：`python -m py_compile backend/app.py`、`git diff --check`。

## 交付边界

- 管理员功能仅在 `frontend` 响应式网页维护，桌面和手机浏览器应保持相同业务规则。
- 员工功能仅在 `uniapp` 微信小程序维护；其中管理员遗留页面保持冻结。
- 不引入新的 UI 框架、状态库、报表库或平行数据表；复用 Flask、Vue、uni-app、SQLite 与既有 `xlsx` 依赖。
