## 有效报货口径

- “有效报货”仅指状态为`已锁定`且具有报货数量的记录，报 0 仍是有效提交。
- 解锁后的旧报货量只供管理员核对，不显示为当前报货，也不参与产品、员工、批次、打印或导出的任何有效合计。
- 员工重新提交并再次锁定后，新数量立即替代旧数量进入所有汇总。
