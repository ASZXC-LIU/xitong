## 命令速查

后端、管理员网页和小程序需要分别在独立终端保持运行：

```powershell
# 后端（项目根目录）
.\backend\start.ps1

# 管理员 Web（frontend 目录）
npm.cmd run dev -- --host 127.0.0.1

# 微信小程序（uniapp 目录）
npm.cmd run dev:mp-weixin
```
