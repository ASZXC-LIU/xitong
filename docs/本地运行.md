# 本地运行与测试数据库重建

## 1. 后端环境

复制 `backend/.env.example` 中的字段到本机环境变量。项目当前不自动读取 `.env`，避免误把真实密钥提交到仓库。

PowerShell 示例（值仅限本地自行设置）：

```powershell
$env:SECRET_KEY = "请替换为本机随机长字符串"
$env:ADMIN_USERNAME = "请设置管理员账号"
$env:ADMIN_PASSWORD = "请设置管理员密码"
$env:ADMIN_DISPLAY_NAME = "管理员"
$env:CORS_ORIGINS = "http://localhost:5173,http://127.0.0.1:5173"
$env:WECHAT_APP_ID = "wxdf7bba648b27e7db"
$env:WECHAT_APP_SECRET = "仅在本机填写真实小程序密钥"
```

安装依赖并显式重建测试数据库：

```powershell
python -m pip install -r backend/requirements.txt
python backend/reset_test_db.py --yes
python backend/app.py
```

`reset_test_db.py --yes` 会删除数据库中的全部测试数据并根据当前模型重建；不会删除任何源码、文档、参考图片或 Excel 样例。

## 2. 管理员 Web

```powershell
cd frontend
npm install
npm run dev
```

管理员 Web 通过 Vite 的 `/api` 代理访问后端，并自动携带登录令牌。

## 3. uniapp 微信小程序

将 `uniapp/.env.example` 复制为本地环境配置，并把 `VITE_API_BASE_URL` 改为当前环境的 API 地址。真机必须使用微信后台配置的合法 HTTPS 域名，不能使用 `localhost` 或 `127.0.0.1`。

```powershell
cd uniapp
npm install
npm run dev:mp-weixin
```

然后使用微信开发者工具打开生成目录 `uniapp/dist`。项目已配置 AppID `wxdf7bba648b27e7db`；员工登录按钮会取得微信一次性手机号凭证和登录凭证，再由后端交换手机号并匹配已启用员工。不要在客户端或仓库中填写 AppSecret。

域名 `aszxc.top` 审核完成前可在微信开发者工具中使用本地调试；真机调试和生产环境必须把后端部署到微信后台已配置的合法 HTTPS 域名。没有真实 AppSecret 时，自动化测试使用依赖注入的模拟微信交换器，不会接受客户端直接提交手机号。

## 4. 验证

```powershell
python -m unittest discover -s backend/tests -v
cd frontend
npm run build
cd ../uniapp
npm run build:mp-weixin
```
